# packages/ui

Shared UI component library built on Tailwind CSS and shadcn/ui.

## Contents

- Theme tokens and design system
- Reusable primitives (Button, Card, Badge, Dialog, etc.)
- ASOSINT-specific threat intel components
- Map and graph visualization wrappers

## Usage

```ts
import { Button, ThreatBadge } from '@aosint/ui';
```
